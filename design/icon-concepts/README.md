# Icon concepts (draft, temporary)

Three playful directions to replace the current road-sign icon. Each is 1024×1024, opaque, with square
corners (iOS applies the mask). `contact-sheet.png` shows every concept at 1024, 180 and 60 px on light
and dark wallpapers. Regenerate with `swift tools/icon_concepts.swift design/icon-concepts`.
The shipped icon is unchanged.

- **A: Speech bubble.** A hand-drawn cream bubble shouting a bouncy, chunky red "STOP!" on a red-orange
  sunburst, with confetti bursting around it: the moment someone shouts "STOP!".
- **B: Letter tiles.** S-T-O-P as chunky red, cream and yellow game tiles tumbling onto a teal board,
  with the "P" sliding in on speed lines: the letter draw and the race to fill in the words.
- **C: Mascot.** A round, cheerful stop-sign creature with big eyes, an open-mouthed shout and a raised
  white-gloved hand, on sunny yellow. It keeps the stop-sign link but makes it fun.
